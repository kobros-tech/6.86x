# Sentiment Labelled Sentences dataset

The project notebooks use the **Sentiment Labelled Sentences** dataset from the UCI Machine Learning Repository.

- 3,000 labelled sentences
- 1,000 IMDb sentences
- 1,000 Amazon sentences
- 1,000 Yelp sentences
- 500 positive and 500 negative sentences from each source
- Labels are converted from `0/1` to the classifier convention `-1/+1`

The notebooks download the archive into this directory when it is not already present; the dataset itself is not committed to the repository.

Source: Kotzias, D. (2015), *Sentiment Labelled Sentences*, UCI Machine Learning Repository, DOI 10.24432/C57604.
