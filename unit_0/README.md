# Unit 0 — Brief Prerequisite Reviews

Unit 0 contains the brief prerequisite material needed before the main machine-learning units.

## Contents

### Brief Review of Vectors, Planes, and Optimization

A concise review of the mathematical foundations used throughout the course, including vectors, planes, linear algebra, and basic optimization concepts.

### Project 0 Setup, Numpy Exercises, Tutorial on Common Packages

Introduces the Python environment and the common packages used in the course, with NumPy exercises and project setup work.

## Role in the course

Unit 0 is a prerequisite review. It does **not** contain the linear-classifier lectures.

The linear-classification material begins in **Unit 1 — Linear Classifiers and Generalizations**.
